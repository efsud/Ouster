MAE is longitudinal mean absolute position error, averaged equally per accepted gap. Moving gaps have more than 5 m of withheld position range. Linear interpolation is scored on exactly the same accepted cases. Cases across durations overlap and are not independent. Stopped vehicles can lower overall errors; rejected gaps remain unavailable. The same thresholds were used without tuning on these cases.

Important failure: unseen stopping and acceleration can produce large errors even when endpoint checks pass. Low average error does not make every dashed line accurate. Real occlusions may differ from artificially hidden data. Provisional alignment and sensor timing also limit accuracy claims.

Decision: keep this candidate experimental. Westbound 10/60-second speed improves, but results are mixed and some flow and longer-horizon errors worsen. The existing dashboard model has not been replaced. Aggregate endpoint forecasts are separate from the local interpolation above; neither validates trajectories in the unobserved road between sensors. Raising the speed prior also worsened pure CTM errors, so it is not a verified physical calibration.

Software checks include hidden-truth isolation, 30-second boundary handling, discontinuous-ground-truth exclusion and existing model/physics tests. Future models require a fresh held-out period: this later dataset has now been evaluated.
